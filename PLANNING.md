## Core User Stories 
"As a young job seeker, I want to filter opportunities by location so that I can find jobs and learnerships near me without unnecessary travel costs."

"As a tertiary student, I want to search and filter for bursaries by category so that I can secure funding options to pay for my studies."

"As a site visitor, I want to report expired listings or suspicious posts via a simple form so that the portal remains accurate, safe, and trustworthy."

"As a recent graduate, I want to view clear eligibility criteria and required document checklists for each opportunity so that I can prepare my application correctly before applying."

"As an inexperienced job seeker, I want to access career guidance and anti-scam warnings so that I can avoid recruitment fraud and improve my CV and interview skills."

"As a community partner or organization representative, I want to suggest new verified opportunities to the platform so that more youth in our community can access them."

## Controlled Data Schema
To ensure consistent filtering across the portal, all opportunity listings in `data/opportunities.json` use the following controlled values:

### Categories
* Internship
* Learnership
* Bursary
* Skill Programme

### Locations
* Cape Town
* Johannesburg
* Durban
* Remote

### Experience Levels
* No Experience
* Entry Level

### Work Arrangements
* On-site
* Hybrid
* Remote
